# Code of Conduct

## The short version

Be decent. Argue with the work, not the person doing it.

## What is expected

* Assume good faith. Someone who disagrees with a modelling assumption is
  doing the project a favour, not attacking you.
* Criticise claims, code and numbers freely and directly. That is the point of
  the project.
* Do not criticise people. No harassment, insults, or unwelcome personal
  attention, in issues, pull requests or anywhere else this project happens.
* Accept correction gracefully, including when it is yours to accept.

## What is not

Harassment, discriminatory language or imagery, sustained disruption,
publishing anyone's private information, or any conduct that would make a
reasonable person feel unwelcome here.

## Enforcement

Report a problem to the maintainer through a GitHub issue, or privately if the
issue is sensitive. Reports will be reviewed and acted on; that may mean a
warning, or removal from the project's spaces. The maintainer is bound by the
same rules as everyone else.

This is adapted, informally, from the spirit of the Contributor Covenant.
